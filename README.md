# 100 Reasons I Love My Babi 💙

A responsive, sky-blue romantic website made with HTML, CSS, and JavaScript.

## How to run it
1. Download and extract the ZIP.
2. Open the `100-reasons-for-my-babi` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start exploring the reasons!

## Features
- 100 reasons in responsive cards
- Search by text, category, or reason number
- Filter all reasons, favorites, or unread reasons
- Filter by category and sort the list
- Tap a card to mark it read and track progress
- Save favorite reasons
- Random reason surprise modal
- Sky-blue light theme and optional dark theme
- Saves favorites, read progress, and theme in your browser with localStorage
- Copyable personal note
- Keyboard shortcut `/` to focus search, and Escape to close the surprise
- Mobile-friendly layout and reduced-motion accessibility support

## Customize it
- Edit the `reasons` array near the top of `script.js` to personalize the 100 reasons.
- Change the note inside `index.html` to add a personal message.
- Adjust the colors in the `:root` section at the top of `style.css`.

Note: The website uses Google Fonts when internet access is available. It still works without them using fallback fonts.
